# 第 12 章 知识蒸馏：大模型教小模型

> 对应代码：`trainer/train_distillation.py`（248 行）
>
> 本章目标：区分黑盒/白盒蒸馏，理解 Hinton 蒸馏框架的数学（温度软标签 + KL 散度），逐行读懂 MiniMind 的 CE + KL 混合损失蒸馏实现（含 MoE→Dense 场景），了解蒸馏在模型压缩中的定位。

---

## 12.1 蒸馏在做什么：模型压缩的另一条路

压缩模型有三条主要路线：

| 路线 | 思想 | 代价 |
|------|------|------|
| 量化（Quantization） | 降低权重精度（fp16→int8/int4） | 精度损失 + 需校准 |
| 剪枝（Pruning） | 删掉不重要的参数/结构 | 结构工程复杂 |
| **蒸馏（Distillation）** | **小模型（学生）学习大模型（教师）的行为** | 需要访问教师模型（或教师输出） |

蒸馏的核心吸引力：**学生模型不直接学"海量数据 + 硬标签"，而是学教师的"软分布"**——教师的知识（尤其是"哪些候选答案相似"这类细粒度信息）以更高效的方式迁移给学生。

## 12.2 黑盒蒸馏 vs 白盒蒸馏

### 12.2.1 黑盒蒸馏（Black-box）

用教师的**输出文本**（答案）当监督信号训练学生：

$$
\mathcal{L} = \mathrm{CE}(y_{\text{teacher}}, p_{\text{student}})
$$

- 学生只看"老师说了什么"，看不到"老师怎么想的"；
- 严格说就是"对教师生成数据做 SFT"（MiniMind README 明确指出：DeepSeek-R1、Qwen3 的高质量回答、tool call/reasoning 数据都属于黑盒蒸馏信号，`sft_t2t` 数据里已混入大量此类数据）；
- 优点：**无需访问教师模型内部**（API 就能做）；缺点：信息粒度粗。

### 12.2.2 白盒蒸馏（White-box）

额外拟合教师的 **token 概率分布**：

$$
\mathcal{L}_{\text{white}} = \alpha\, \mathcal{L}_{\text{CE}} + (1-\alpha)\, T^2\, \mathrm{KL}\left(p_t^T \parallel p_s^T\right)
$$

- 学生不仅学"答案是 X"，还学"教师认为 X 的候选有 Y、Z，且 Y 比 Z 更接近"——**软标签承载了类间相似度知识**；
- 前提：能访问教师模型的 logits（白盒）；
- `train_distillation.py` 就是白盒参考实现。

## 12.3 Hinton 蒸馏的数学

### 12.3.1 温度软化

教师/学生的概率都经过温度 $T$ 软化：

$$
p_i^{(T)} = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

- $T=1$：原始分布；
- $T>1$：分布变平——**教师对"次优候选"的偏好被放大**（这正是要迁移的知识）；
- 训练用软化分布，推理用 $T=1$。

### 12.3.2 为什么 KL 前乘 $T^2$

软化分布的梯度量级随 $T$ 衰减，乘 $T^2$ 补偿（推导要点：$T \to \infty$ 时 logits 差 $\Delta$ 的梯度贡献 $\propto \Delta / T^2$，需乘 $T^2$ 保持学习率一致）。**这是蒸馏实现最容易漏的细节**。

## 12.4 train_distillation.py 逐行精读

### 12.4.1 核心损失函数（第 25~36 行）

```python
def distillation_loss(student_logits, teacher_logits, temperature=1.0, reduction='batchmean'):
    with torch.no_grad():
        teacher_probs = F.softmax(teacher_logits / temperature, dim=-1).detach()

    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)

    kl = F.kl_div(
        student_log_probs,        # 学生：log 概率（log 域）
        teacher_probs,            # 教师：概率（线性域，做目标）
        reduction=reduction
    )
    return (temperature ** 2) * kl
```

三个关键点：

1. **教师完全冻结**：`torch.no_grad()` + `.detach()`——教师只提供目标信号，不参与梯度；
2. `F.kl_div` 的输入约定：第一个参数要 **log 域**（学生 logprob），第二个参数要**线性域**（教师概率），方向是"学生 ← 教师"（$D_{KL}(p_{\text{teacher}} \parallel p_{\text{student}})$ 的离散求和形式）；
3. `reduction='batchmean'`：按 batch 平均（KL 散度的标准归约）。

### 12.4.2 训练循环中的混合损失（第 47~93 行）

```python
loss_mask = (labels[..., 1:] != -100).float()          # SFT 掩码复用

with autocast_ctx:
    res = model(input_ids)
    student_logits = res.logits[..., :-1, :].contiguous()

if teacher_model is not None:
    with torch.no_grad():
        teacher_logits = teacher_model(input_ids).logits[..., :-1, :].contiguous()
        vocab_size_student = student_logits.size(-1)
        teacher_logits = teacher_logits[..., :vocab_size_student]   # ★ 词表对齐

# 1) Ground-Truth CE Loss（硬标签）
ce_loss = F.cross_entropy(student_logits.view(-1, V), shift_labels.view(-1), ignore_index=-100, reduction='none')
ce_loss_raw = torch.sum(ce_loss * loss_mask_flat) / (loss_mask_flat.sum() + 1e-8)

# 2) Distillation Loss（软标签）
distill_loss = distillation_loss(
    student_logits.view(-1, V)[loss_mask_flat == 1],
    teacher_logits.view(-1, V)[loss_mask_flat == 1],
    temperature=temperature
)

# 3) 总损失
loss = (alpha * ce_loss + (1 - alpha) * distill_loss) / args.accumulation_steps
```

**词表对齐**（第 66 行）：学生词表 6400，教师若用更大词表，只取前 `vocab_size_student` 维——**蒸馏要求两模型词表兼容**（同一 tokenizer），这是 MiniMind 系列蒸馏（dense↔moe 同词表）可行的前提。若词表不同，需要投影层（工业界做法，超出本项目范围）。

**掩码应用方式**：CE 用 `ignore_index=-100`，KL 用显式 `loss_mask_flat == 1` 筛选——两种掩码哲学（index 掩码 vs 布尔筛选）的对照示范。

**α 的语义**（默认 0.5，`--alpha`）：

- α=1：纯 SFT（无蒸馏）；
- α=0：纯蒸馏（只学教师分布，不碰硬标签）；
- α=0.5：各半——**硬标签锚定"正确答案"，软标签传递"教师偏好"**。

> 注意：数据仍是 `sft_t2t_mini.jsonl`（对话数据），蒸馏在 SFT 数据上做——即"教师 + 学生共同读同一批对话，学生学教师的分布"。README 建议在已完成 SFT 的权重上继续蒸馏。

### 12.4.3 教师/学生配置（第 146~177 行）

```python
parser.add_argument('--student_hidden_size', default=768, ...)
parser.add_argument('--student_num_layers', default=8, ...)
parser.add_argument('--teacher_hidden_size', default=768, ...)
parser.add_argument('--teacher_num_layers', default=8, ...)
parser.add_argument('--student_use_moe', default=0, ...)   # 学生 Dense
parser.add_argument('--teacher_use_moe', default=1, ...)   # 教师 MoE（默认演示 MoE→Dense 蒸馏）
parser.add_argument('--alpha', default=0.5, ...)
parser.add_argument('--temperature', default=1.5, ...)     # 推荐 1.0~2.0
```

默认场景：**198M-A64M 的 MoE 教师 → 64M Dense 学生**（"用大模型教小模型"的最典型演示）。支持任意 hidden_size/层数组合（教师 768 层 16 层 → 学生 512 层 8 层也可以，只要词表一致）。

其他工程细节与主线脚本一致：教师 `requires_grad_(False)` + `eval()`；学生 `--from_student_weight full_sft` 起训；学习率 5e-6（介于 SFT 与 RL 之间）；`--save_weight full_dist`。

## 12.5 动手实验

### 实验 12.1：MoE → Dense 蒸馏

```bash
# 前提：MoE 教师权重（full_sft_768_moe.pth，需先训练或下载）+ Dense 学生权重（full_sft_768.pth）
cd trainer
python train_distillation.py --epochs 3
```

预期日志（三个损失分量分开打印）：

```text
学生模型总参数量：63.910 M
教师模型总参数量：198.xxx M
Epoch:[1/3](100/…), loss: 1.2100, ce: 0.6800, aux_loss: 0.0000, distill: 0.5300, ...
```

解读：

- `ce`：硬标签损失（与 SFT 同源，应持续下降）；
- `distill`：KL 损失（教师分布拟合程度，初期较大、逐渐减小）；
- 总 loss = α·ce + (1-α)·distill，日志把三者分开便于观察教师信号的作用。

### 实验 12.2：蒸馏效果对比

```bash
python eval_llm.py --weight full_dist        # 蒸馏学生
python eval_llm.py --weight full_sft         # 普通 SFT 学生
python eval_llm.py --weight full_sft --use_moe 1   # MoE 教师（需对应权重）
```

用同一批问题对比三者的回答质量。可观测的典型结论：

- 蒸馏学生 ≥ 普通学生（同等参数量下，软标签带来收益）；
- 蒸馏学生 < MoE 教师（教师天花板仍在）；
- **参数量差距越大，蒸馏收益越明显**（64M 学生从 198M 教师学到的"暗知识"占比更高）。

### 实验 12.3：温度的影响（可选）

```bash
python train_distillation.py --temperature 1.0 --epochs 1   # 无软化
python train_distillation.py --temperature 2.0 --epochs 1   # 强软化
```

对比 distill 损失曲线：T=1 时教师分布尖锐、KL 大；T=2 时软化后 KL 更小但信息更丰富。可配合 α=0 观察纯蒸馏行为。

## 12.6 本章小结

- 蒸馏 = 学生学教师的"软分布"，是模型压缩三大路线之一（量/剪/蒸）；
- 黑盒蒸馏 = 学教师输出文本（本质是 SFT），白盒蒸馏 = 额外学教师 token 分布（需 logits 访问）；
- 核心数学：温度软化 $p^{(T)}$ + KL 散度 + $T^2$ 梯度补偿；
- 实现要点：教师冻结、`F.kl_div` 的 log/线性域约定、词表对齐（截断）、掩码双哲学、α 混合权重；
- 默认演示 MoE(198M) → Dense(64M)，同词表是可行前提；
- 蒸馏收益随师生差距增大而增大，但学生天花板仍受教师限制。
