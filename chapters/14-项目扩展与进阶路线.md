## 14.1 你已经掌握了什么

对照最初的学习目标，现在你应该已经：

- ✅ 完整理解从 0 训练 LLM 的流水线（Tokenizer → Pretrain → SFT → RL → 部署）；
- ✅ 逐行读懂模型实现（RMSNorm/RoPE/GQA/SwiGLU/MoE）；
- ✅ 亲手训练并部署了自己的 64M 模型；
- ✅ 理解 LoRA/DPO/PPO/GRPO/蒸馏/Agentic RL 的原理与代码；
- ✅ 理解 RLVR、自适应思考、KV Cache、混合精度、断点续训等工程细节。

这些知识**不随模型大小缩放**：7B 模型的机制与你训练的 64M 模型完全同构。

## 14.2 扩展方向一：MoE 深入

MiniMind 的 MoE 是教学级简化（4 experts / top-1，朴素实现）。工业级 MoE 的进阶课题：

| 课题 | 说明 | 相关资源 |
|------|------|----------|
| 更多专家/更大 top-k | 参数量与激活量的权衡 | DeepSeek-MoE（256 experts, 8 active） |
| 负载均衡的精细设计 | aux loss 变体、Expert Choice 路由 | 《Mixture-of-Experts with Expert Choice Routing》 |
| 稀疏内核优化 | kernel-fused 算子（Triton/Megatron） | README 中关于 MoE 训练开销的讨论 |
| 专家共享（shared expert） | Qwen3-MoE 的设计（README 提到已移除 shared expert） | Qwen3 技术报告 |

**动手建议**：用 `--use_moe 1` 训练对比 Dense 版本，观察参数量打印（`198M-A64M` 格式）、aux_loss 曲线、训练速度差异。

## 14.3 扩展方向二：长上下文

MiniMind 训练长度 340~768，推理靠 YaRN 外推到 2~4 倍。工业界的长上下文路线：

1. **训练阶段**：长序列数据（Books、代码仓库）+ 长上下文训练技术（序列并行、flash attention、环形注意力）；
2. **位置编码改进**：YaRN / NTK-aware / Dynamic NTK 外推（免训练或轻量微调）；
3. **工程优化**：KV Cache 量化（KVQuant）、稀疏注意力（Sliding Window、H2O）、Prefix Cache。

**动手建议**：对比 `--inference_rope_scaling` 开关前后，`max_new_tokens=8000` 时输出的质量退化形态（死循环重复 vs 语义漂移）。

## 14.4 扩展方向三：多模态

MiniMind 系列已拓展：

- **MiniMind-V**：视觉语言模型（LLM + 视觉编码器对齐）；
- **MiniMind-O**：全模态 Omni 模型；
- **MiniMind-dLM / MiniMind-Linear**：扩散语言模型 / 线性注意力（实验性）。

词表里预留的多模态标记（`<|image_pad|>`、`<|video_pad|>` 等，第 3 章见过）正是为这些扩展准备的接口。

## 14.8 实验工具箱（本教程之外值得做的 10 个实验）

1. 换学习率三组（5e-4 / 5e-3 / 5e-5）跑 500 步，对比 loss 曲线——建立"lr 敏感度"体感；
2. `d_model` 与 `n_layers` 的等参数量对调（如 1024×4 vs 512×16）——验证 MobileLLM 结论（README 讨论）；
3. 换 `rope_theta`（1e4 vs 1e6）——观察长序列 loss 变化；
4. 数据增强消融：关闭 `pre_processing_chat`/`post_processing_chat`，对比 SFT 效果；
5. 梯度裁剪消融（clip=0.1 vs 10）——观察 loss 尖峰处理差异；
6. LoRA rank 消融（4/16/64）；
7. DPO β 消融（0.05/0.15/0.5）；
8. 蒸馏温度消融（T=1/1.5/2.0）；
9. num_generations 消融（GRPO，G=2/6/12）；
10. 在 2 卡 DDP 上跑 pretrain，对比单卡吞吐与 loss 一致性。
